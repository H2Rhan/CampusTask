## 现场 Demo 流程（防翻车版）

> 演示前 5 分钟：`rm campustask.db && python -m scripts.seed && uvicorn app.main:app`

1. **AI 发布**（30 秒）
   `POST /api/v1/ai/parse`：`下午五点去西门菜鸟驿站拿快递送到中海，给5块`
   → 展示结构化结果（type/start/destination/deadline/reward 全中）
2. **边际成本匹配**（60 秒，核心）
   发布任务 → `GET /api/v1/match/tasks/{id}/candidates`
   → 讲解：李同学路线经过西门，MC=420m，匹配度 80%；张同学在东区，MC=2415m，36%
   → 金句：**"人找任务，变成任务找人"**
3. **批量调度**（30 秒，数维杯伏笔）
   再发一单 → `GET /api/v1/match/batch-assign`
   → 匈牙利算法给出全校总边际成本最小的分配方案
4. **可信交易**（45 秒）
   李同学接单 → 快捷操作走完状态机 → 发布者验收 → 展示双方钱包流水
5. **仲裁**（30 秒，备用环节）
   新任务中发布者发起仲裁 → 展示规则引擎意见 → 管理员裁决 → 资金退回
