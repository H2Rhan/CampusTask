## 2. 各版本差异化要点

### ① 华为 ICT 创新赛（产品版本）

- 叙事主线：**AI + ICT 综合应用，智慧校园真实场景**
- 必须突出：AI 任务理解 → 智能匹配 → 校园地图 → 路径规划 → 信用 → 仲裁 全链路
- 加分项：昇腾/ModelArts 推理、华为云部署、鸿蒙形态
- 交付物：可运行 Demo + 技术架构文档 + 3 分钟演示视频

### ② 数维杯（算法版本）

- 独立成果：**基于边际出行成本的校园任务智能分配与多任务路径优化**
- 核心模型：`MC = T(原路线 + 任务) − T(原路线)`；系统目标：全校任务总边际成本最小
- 扩展：单任务插入 → 多任务批量分配（CVRP/指派问题，匈牙利算法/启发式）
- 与产品版本的关系：算法在 `server/app/services/matching_service.py` 中有工程实现，论文做理论深化

### ③ 经开杯 / 创新创业能力大赛（商业版本）

- 叙事主线：**校园本地即时服务交易平台**（类三创赛 AI 电商逻辑）
- 必须突出：用户增长、真实运营数据、盈利模式（低额撮合服务费）、市场规模测算
- 关键动作：W7–W8 内测攒数据（见 ROADMAP.md 运营指标）
